Version 0.4.0 - Visual Redesign & Sound Library Sept, 2025

Changed

  • UI Redesign - Updated interface to be more user-friendly and visually appealing
  • Sliding Panel - New design includes a sliding panel for easy access to the Sound Library
  • Card Layout - More organized layout with redesigned sound cards
  • Alphabetical Sorting - Cards are displayed in alphabetical order and show each sound's name
  • Improved Drag & Drop - You can now drop sounds into the list instead of needing to drop on category names

Replaced

  • Sound Library - Soundpad sounds replaced with a comprehensive Sound Library containing all previous soundpad sounds
  • Automatic Sound Type - New "Soundpad UI" sound type that automatically adds sounds to the soundpad interface
  • Simplified Configuration - No longer need to configure categories in settings for the soundpad UI

Improved

  • Better sound organization and easier management
  • Enhanced user experience for moving sounds between categories
  • Streamlined workflow for soundpad integration

Version 0.3.6 - Western Soundscape Aug, 2025

Added

  • Downloadable Western Soundscape JSON file
  • Prevents future updates from overwriting local soundscape changes
Download Western.json

Installation Steps

  1. Download and save the file above into your FoundryVTT data folder
  2. Click on "Load Soundscape" in the module
  3. Locate and import the file western.json
  4. Enjoy the sounds of the Wild West at your table!
