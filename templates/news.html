Version 0.3.0 - FoundryVTT 13 June, 2025

Important: This version is not compatible with your old moods. Please watch the short video guide below to learn how to import them.

This is a beta release for stability testing. If you find any bugs, please don't hesitate to open an issue on GitHub.

  • Removed Folder structure dependency: There's no need to organize sounds into specific folders anymore. Everything is configured through the UI now!
  • Removed Ambience sounds: The type Ambience is now removed from the Soundscape.
  • Changed Reworked random sound management: The system now provides a more robust and stable way to handle random sounds.
  • Added Foundry VTT v13 support! The module is now fully compatible with the latest version.
  • Added Drag & Drop songs: Easily move sounds between types (loop, random, soundpad) using the new UI interface.
  • Added Categories for sound types: Organize your sounds with custom categories inside each type. You can now also control categories with Play All and Stop All actions.

Please watch the videos below to learn how to import your old moods to the new Soundscape Adventure.
