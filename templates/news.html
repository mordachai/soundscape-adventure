Version 5.0.7 - Fade in/out May, 2026

This new version contains an initial fix for the fade in/out functionalities and a fix for the scene configuration.

  • Fade Out: Uses the native fade-out functionality provided by Foundry VTT. Keep in mind that the sound may keep playing for a while after being stopped.
  • Fade In: Linearly ramps the sound volume from 0 to the configured volume.
  • Scene Configuration: The option to play a mood when activating a scene is now working for Foundryvtt v14.

These fixes are still in a testing phase, and I'm still exploring alternative ways to implement these fade effects.

If you're experiencing any issues with the module, please let me know by creating an issue on GitHub here.

Version 5.0.6 - Loop sounds on changing moods Apr, 2026

Now when you change mood, if the new mood has the same loop sound as the previous mood, the sound will continue to play without interruption.

For example, if you have a rain loop sound in both the "Calm" and "Stormy" moods, switching between these moods will not stop the rain sound, allowing for a seamless transition.

For group loops, if the intensity changes, the sound will transition as usual.
