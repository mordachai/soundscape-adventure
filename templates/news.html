Version 0.3.4 - New Soundscape Available – Western! July, 2025

With this update, you can now import a brand-new soundscape filled with Western-themed sounds – perfect for games like Deadlands or any campaign set in the dusty frontier.

What’s included?

I've been using these sounds in my own Deadlands sessions, and now I’m sharing them with you! The update includes:

  • Over 100 new sounds, including ambient effects, loops, and random sounds.
  • A ready-to-use example soundscape to help you get started building your own moods and settings.

How to use it:

  • Click on the Load Soundscape
  • Locate and import the file western.json (it is located in the soundscape module folder within the soundscapes folder)
  • Enjoy the sounds of the Wild West at your table!

If you have any problems or questions, please feel free to reach out opening a issue on github using the issue tracker.
