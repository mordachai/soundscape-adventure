Version 0.3.7 - We are excited to introduce a new feature: Soundpad! 🎛️ Aug, 2025

Soundpad lets GMs play sounds without opening the soundboard.
It provides quick access to sounds, allows images for easy identification, and uses a configurable category to show only useful sounds in the Soundpad UI.

To learn more about the soundpad, click on the image below to watch the video.

Version 0.3.6 - Downloading the Western Soundscape! Aug, 2025

Since some users have asked how to use the pre-made Western Soundscape,
and to ensure future updates won’t overwrite any local changes that you might make to the soundscape.
Please download the JSON file below and place it in your FoundryVTT data folder.

click here to open Western.json in a new tab

How to use it:

  • Download and save the file above into your FoundryVTT data folder.
  • Click on "Load Soundscape".
  • Locate and import the file western.json
  • Enjoy the sounds of the Wild West at your table!

If you have any problems or questions, please feel free to reach out opening a issue on github using the issue tracker.
