Version 5.1.0 - Common group issues fixedMay, 2026

This new version contains fixes for some bugs related to group sounds. Groups had several issues in previous versions that made them a pain to manage. These fixes aim to make it easier to delete and move groups.

  • Delete Groups: You can now delete a group from its configuration dialog.
  • Moving Groups: When you move a group from Loop Sounds to Random Sounds, the group changes its type.
  • Other fixes: Code improvements to make sure random and loop groups will follow group settings and not sound settings.

If you're experiencing any issues with the module, please let me know by creating an issue on GitHub here.

Version 5.0.10 - Layout Fixes and Fade effects ConcludedMay, 2026

This new version contains some layout fixes and the final version for the fade effects.

  • Layout Fixes: The layout improvements and adjustments fixes the scrolling behaviour.
  • Layout Fixes: The Sound Config Button has been removed. Now, to configure a sound you click on the sound's icon. This removes the need for a separate configuration button.
  • Fade Effects: The effects are now implemented. Fade-out is using the native effect. Fade-in is implemented using custom gain node that applies a linear gain.

If you're experiencing any issues with the module, please let me know by creating an issue on GitHub here.
